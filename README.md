# andikaMaulana.github.io

Halaman profil pribadi Andika Maulana — live di **https://andikamaulana.github.io**.

Satu file `index.html` statis (tanpa build step):

- Hero dengan terminal animasi
- Fokus & keahlian, proyek unggulan, dan timeline perjalanan
- Daftar repositori yang diambil langsung dari GitHub API, bisa difilter per bahasa
- Mode gelap / terang (mengikuti sistem, bisa diganti manual)

Untuk mengubah proyek unggulan, edit array `featured` di bagian `<script>` pada `index.html`.
